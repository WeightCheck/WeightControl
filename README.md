Weight Control
Android app for calculating:

Machine Dryness
Moisture Content
Wet Weight
Wet Should Be
Bone Dry Weight
Target Bone Dry Weight
Deviation
Built with Kotlin and Jetpack Compose.

Formulae:

Machine Dryness = (Bone Dry / Wet Weight) × 100

Moisture Content = ((Dry Weight - Bone Dry) / Dry Weight) × 100

Wet Should Be = (Target Bone Dry / Machine Dryness) × 100
